# OPC 智能工作台：部署到你的服务器

部署包 `opc-site.tar.gz`（由仓库里的 `site/` 和 `deploy.sh` 打包而成）里有 6 个页面（纯静态网站，不依赖外部 CDN），以及一个一键部署脚本 `deploy.sh`。脚本会安装 nginx，并把网站放到 80 端口。

## macOS 步骤

1. 下载 `opc-site.tar.gz`（默认会存到“下载”文件夹）。
2. 打开“终端”：按 Command + 空格，输入“终端”后回车。
3. 依次运行下面的命令，提示输入密码时粘贴服务器密码：

```
cd ~/Downloads
scp -P <SSH端口> opc-site.tar.gz root@<服务器IP>:/root/
ssh -p <SSH端口> root@<服务器IP> "tar xzf opc-site.tar.gz && bash opc-site/deploy.sh"
```

第一次连接时会问 `Are you sure you want to continue connecting`，输入 `yes` 后回车。

## Windows 步骤（Windows 10/11 自带 ssh，不用装软件）

1. 把 `opc-site.tar.gz` 下载到电脑上，例如放到桌面。
2. 在桌面空白处按住 Shift 并点右键，选择“在此处打开 PowerShell 窗口”。
3. 上传部署包，提示输入密码时粘贴服务器密码（输入时屏幕不显示，属于正常现象）：

```
scp -P <SSH端口> opc-site.tar.gz root@<服务器IP>:/root/
```

4. 登录服务器并执行部署，同样需要输入一次密码：

```
ssh -p <SSH端口> root@<服务器IP> "tar xzf opc-site.tar.gz && bash opc-site/deploy.sh"
```

5. 看到“部署完成”后，用浏览器打开 http://<服务器IP>/

## 打不开怎么办

- 到服务商后台，进入这台服务器的“安全组”，放行 TCP 80 端口。
- 第 4 步如果报软件源错误，脚本会自动切换到 Debian 归档源重试。仍然失败的话，把报错内容发给我。

## 部署完成后请务必修改密码

为安全起见，部署完成后，请登录服务器执行下面的命令，换一个新密码：

```
ssh -p <SSH端口> root@<服务器IP>
passwd
```

## 以后更新网站

拿到新的部署包后，重复第 3、4 步即可。脚本会覆盖旧文件。
