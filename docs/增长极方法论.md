# 增长极方法论

本项目的前身是「创越企业增长极」（GrowthHubs，growthhubs.com.cn）：创越咨询、高科咨询、北京卡普兰平衡计分卡研究院、国澍投资联合发起的企业增长咨询平台。两位资深顾问退出后项目搁置，网站即将关闭，已于 2026-10-25 全站存档（存档不在仓库里）。

完整分析见 [旧网站梳理与 AI 时代方案调整建议](https://claude.ai/artifact/1JTKrCHfheNx6i28V2qqjJ)。

## 旧网站的业务框架

| 板块 | 内容 |
| --- | --- |
| 核心业务 | 增长能力评估 → 增长战略规划 → 增长执行系统规划 → 增长梯队孵化 → 增长绩效咨询 |
| 6 套增长系统 | 多业务（母合）、可持续增长组合、主导性业务、业务价值链、跨区域、利基市场 |
| 自有模型 | 增长竞争五力、战略肆力、双核心能力、五项增长极、VGEM、四梯队管理 |
| 增长商学 | 6 个增长训练营 + 指数型组织、战略选择与规划两个共创营 |
| 增长研究院 | 49 篇文章（上市公司增长拆解、方法论、约 20 个平衡计分卡咨询案例） |
| 社群 | 增长时刻、增长实验室、增长私董会 |
| 资源中心 | 56 份行业报告，注册下载 |

## 在原型里的用法

- `site/assets/growth-model.js`：五力题目、6 套增长系统（适用企业类型、核心要素、配套训练营）和推荐规则。
- `site/checkup.html`：企业主做五力自评，每题 1–5 分，每项力 = 平均分 × 20，低于 60 为短板；推荐规则 = 企业类型匹配 3 分 + 增长意图匹配 3 分 + 每补一项短板 1 分。
- `site/diagnose.html?system=<key>`：显示匹配的增长系统和诊断命中的要素。
- `site/proposal.html?system=<key>`：方案模板名随增长系统变化。

体检题目是原型措辞，正式使用前需要顾问校准。方法论和案例的使用需先取得原作者授权。
