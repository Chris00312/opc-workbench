# DECISIONS

## 2026-10-08 UI 风格：Stripe 后台风格
- 选项：卡片堆叠的“AI 模板”风格 vs Stripe 后台风格。
- 决定：Stripe 风格（白底、细分隔线、表格、单一蓝色强调色、浅灰侧栏）。
- 原因：用户认为卡片风格显得廉价。以后的 UI 继续用这个风格。

## 2026-10-08 分阶段推进
- 决定：先做培训（用现成工具），再把 AI 工具产品化，最后做撮合平台。
- 原因：降低前期投入，先验证需求。

## 2026-10-14 部署方式：纯静态 + nginx
- 决定：静态页面打包，用户在自己的 VPS 上运行 deploy.sh。
- 原因：原型无后端；云端会话无法 SSH 到用户服务器。

## 2026-10-25 仓库不含敏感信息
- 服务器 IP、SSH 端口、密码一律不入库，文档里用占位符。原计划书 PDF 不入库。
