# DECISIONS

## 2026-10-08 UI 风格：Stripe 后台风格
- 选项：卡片堆叠的“AI 模板”风格 vs Stripe 后台风格。
- 决定：Stripe 风格（白底、细分隔线、表格、单一蓝色强调色、浅灰侧栏）。
- 原因：用户认为卡片风格显得廉价。以后的 UI 继续用这个风格。

## 2026-10-08 分阶段推进
- 决定：先做培训（用现成工具），再把 AI 工具产品化，最后做撮合平台。
- 原因：降低前期投入，先验证需求。

## 2026-10-14 部署方式：纯静态 + nginx
- 决定：静态页面打包，用户在自己的 VPS 上运行 deploy.sh。
- 原因：原型无后端；云端会话无法 SSH 到用户服务器。

## 2026-10-25 仓库不含敏感信息
- 服务器 IP、SSH 端口、密码一律不入库，文档里用占位符。原计划书 PDF 不入库。

## 2026-11-01 定位：中型企业 + 极增品牌
- 决定：公司“极增科技”，内容/报告品牌“极增商界”；主客户 100–150 人企业；个人/小机构订阅版是第二产品线，后做。
- 影响：OPC 顾问工作台（site/）作废。

## 2026-11-01 官网风格：深色科技风（参考 51WORLD）
- 选项：沿用 Stripe 后台浅色风 vs 用户指定的 51WORLD 官网风格。
- 决定：官网用深色 + 全屏视频 + 竖版产品卡 + 路线图，主色青绿 #19d3b0、辅色琥珀。Stripe 风格仍用于产品内部后台界面。
- 素材：只用 Pexels / Mixkit 可商用素材，本地托管（不外链），来源列在 credits.html。
