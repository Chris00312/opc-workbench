# WORKBENCH_SPEC — 经营工作台（产品 3）产品形态规格

## 1. Positioning
- Proactive, goal-driven AI "经营秘书" living inside 企业微信 / 钉钉 (later 飞书) + a web workbench for meeting projection. NOT a dashboard / "AI 问数" product (incumbents 金蝶/钉钉/企微 bundle passive AI for free).
- Tagline: 别的 AI 等你来问，极增的 AI 盯着你的目标，追着团队把事办成。
- AI front stage, consultants back stage (review key pushes, chair monthly meeting, big issues). Industry knowledge = client middle managers + AI over peer annual reports/public data + 行业包.
- Inspired by Meta Muse (proactive personal agent, 2026-09); never use the Muse name in marketing.
- Target: 小公司 → 成长型企业 (has middle managers). Pilot industry: 经贸公司.

## 2. Touchpoints
晨报 (workdays 8:30, exceptions only, ≤1/day) · 随时问 (answer with data source + one-tap forward) · 追中层 (as "张总想了解…", never impersonate boss) · 月度经营会 (AI collects reasons before meeting, drafts material, projected on web) · 行动项 (owner + due, weekly Monday nudges, escalate overdue) · 年度目标拆解 (dept × month).

## 3. Proactivity levels
① 提醒 (no confirm) ② 建议 (boss glances) ③ 代办 needs one-tap confirm ④ 授权范围内自动做. Pilot: ③④ reviewed by consultant before sending. Anti-noise: exceptions only, weekly caps per person, levels adjustable, every number cites source.

## 4. Platform feasibility (verify against official docs before dev)
- Push: 钉钉 工作通知 / 机器人单聊; 企微 应用消息. Confirm buttons: 钉钉 互动卡片, 企微 模板卡片 (callbacks). Chat: 钉钉 robot (Stream mode), 企微 智能机器人 API mode. Chat bots are mostly passive-reply → proactive goes through app push channel.
- Limits: bot sees only @/single chats; no business data in IM → connectors (Excel upload first, then 金蝶/用友 OpenAPI); messages sent as app identity.
- Install: pilot = 企微 代开发应用 (customer scans, ~10 min, we configure); product = 第三方应用 (scan/market, ~3 min). Never 自建应用 for customers (domain/IP/callback config burden). Need 企微服务商 registration; 接口调用许可 per-user fee paid by provider.
- Onboarding: scan install → AI chat asks goals → pick owners from contacts → upload 12-month Excel → next-morning first 晨报. Pilot: consultant-assisted ~1h; target self-serve 15 min for small firms.
- Architecture: reuse report product's LLM abstraction/auth/DB/deploy (TECH_SPEC); new = IM platform adapter layer, connectors, goals & action items, proactive engine, web workbench.

## 5. Editions (price ranges = suggestions, boss to decide)
Free AI 经营体检 (Excel → 10-min health check, lead gen) · 小公司版 pure AI 300–800 元/月 · 成长型 AI + 顾问陪跑 8–20 万/年 · add-ons (ERP integration, diagnostics, private deploy).

## 6. Pilot
Prep 4–6 weeks (MVP: 代开发应用 + Excel + 晨报 + 随时问 + 追问卡片 + 经营会材料 + 行动项; reviewer back office; 经贸行业包 v1) → 3–5 经贸公司 × 3 months → review. KPIs: boss opens/replies ≥3/wk; manager reply rate ≥70%; meeting prep 2–3 days → ≤half day; AI push pass rate ≥80% by month 3; ≥2 willing to pay.
